3. Built-in colormaps (Rendering/ColorThemes.cs)
-------------------------------------------------------------------------
This library ships a set of built-in color lookup tables. Most are original
implementations, or well-known formulas computed here from scratch, and carry
no attribution requirement. One - Turbo - embeds third-party licensed data:

  Turbo
    Component: the official 256-entry Turbo lookup table embedded in
               ColorThemes.CreateTurbo (Rendering/ColorThemes.cs)
    License: Apache License, Version 2.0 (SPDX-License-Identifier: Apache-2.0)
    Copyright: Copyright 2019 Google LLC.
    Reference: https://ai.googleblog.com/2019/08/turbo-improved-rainbow-colormap-for.html

    The full license text is reproduced below under "LICENSE TEXT (APACHE
    LICENSE 2.0)". It applies to that lookup table data only - not to the rest
    of ColorThemes.cs, and not to MxPlot as a whole; Apache 2.0 places no
    copyleft / share-alike obligation on the surrounding code.

The remaining built-in colormaps need no attribution. Several do follow color
schemes devised by other people, though, and our thanks go to them for such
fascinating work - the credits below are a courtesy, not something a license
asks for:

  Grayscale, Hot, OrangeHot, GreenHot, Cold, BSMod, Spectrum, Phase, HiLo
    Original implementations (no restrictions).

  Jet
    The classic MATLAB-style rainbow ramp, computed here from the standard
    piecewise formula rather than copied from any implementation.

  Viridis
    Approximated by interpolating five control points taken from the
    Matplotlib colormap of the same name, designed by Eric Firing,
    Nathaniel Smith and Stefan van der Walt and released into the public
    domain (CC0).
    Reference: https://matplotlib.org/stable/users/explain/colors/colormaps.html

  CoolWarm
    After Kenneth Moreland's diverging color map, published for unrestricted
    use.
    Reference: https://www.kennethmoreland.com/color-advice/

4. Material Design Icons (Helpers/MenuIcons.cs)
-------------------------------------------------------------------------
Source: https://github.com/Pictogrammers/MaterialDesign-SVG (the icon set
        formerly maintained as Templarian/MaterialDesign)
License: Pictogrammers Free License - the icons themselves are distributed
         under the Apache License, Version 2.0 (SPDX: Apache-2.0)
Copyright: Pictogrammers

Helpers/MenuIcons.cs stores menu and toolbar icons as StreamGeometry path
strings. Some are upstream glyphs used as they are, some are upstream glyphs
modified here (coordinates adjusted, subpaths reordered, parts removed or
extra detail added), and some were drawn for MxPlot with no upstream
counterpart. Which is which is recorded in that file, as a one-line comment
above each icon declaration - that is the authoritative record, kept next to
the data it describes rather than duplicated here.

The full license text is reproduced below, under the heading "LICENSE TEXT
(APACHE LICENSE 2.0)".

Notes and distribution guidance
-------------------------------------------------------------------------
- The above list reflects the packages detected by `dotnet-project-licenses`.
- If you later add or bundle other packages (for example SkiaSharp or native Skia
  binaries), include their license texts and copyright notices as required.
- If your NuGet package or distribution **bundles native binaries** (e.g. native
  Skia .dll/.so/.dylib), you must include the native component's license (for
  Skia: BSD-3-Clause style) in addition to SkiaSharp's MIT notice.
- Before publishing a NuGet package, verify the actual files included in the
  package and ensure all required license texts are present.
- Sections 3 and 4 cover data vendored into this library's own source rather
  than NuGet dependencies, so license scanners such as `dotnet-project-licenses`
  will not report them - keep those sections in sync by hand when colormaps or
  icons change.
