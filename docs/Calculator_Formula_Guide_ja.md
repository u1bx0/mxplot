# Calculator と数式のガイド

**MxPlot.UI.Avalonia / MxPlot.App**

> 最終更新: 2026-11-26（v0.7.0）

数式は、画素ごとに新しい値を計算します。画素の座標、軸の位置、1 つ以上のウィンドウのデータを使えます。
結果は常に `double` です。

## Calculator と Create Data

| | Calculator | Create Data |
|---|---|---|
| 場所 | `MatrixPlotter` の **Processing > Calculator…** | MxPlot.App のメインメニューの **Create Data…** |
| 読むデータ | そのウィンドウのデータ（`m1`） | 任意の数のウィンドウ（`m1`、`m2`、…）。なしでもよい |
| 結果のグリッドと軸 | ソースと同じ | 自分で定義するか、参照ウィンドウと同じ |
| ソースへの追従 | **Sync source data** | **Keep updated** |

どちらのダイアログでも、次の操作ができます。

- **?** ボタンで、演算子と関数の一覧（検索可能）を表示します。
- **上下キー**（または ▾ ボタン）で、同じセッションで適用した数式を呼び出します。
- 数式に誤りがあると、入力欄に色が付き、内容が表示されます。

### Calculator

数式を入力して **Apply** を押します。複数フレームのデータでは、**This frame only** をチェックしない限り、
スタック全体を処理します。どちらの場合も、`m1` はソースのどのフレームでも読めます。
**Replace data** は、新しいウィンドウを開かずに、そのウィンドウのデータを置き換えます。

### Create Data

1. 必要に応じて、**+ Add Window…** で参照ウィンドウを追加します。順に `m1`、`m2`、… という名前になります。
   MxPlot.App では、ウィンドウを選択してからダイアログを開くと、それらが参照になります。
2. 出力のグリッドを決めます。参照がある場合、**Custom size / scale** をチェックしない限り、
   グリッドと軸は **From:** で選んだウィンドウのものになります。軸は **+ Z**、**+ Channel**、**+ Time**、
   **+ Other** で追加します。
3. 数式を入力して **Create** を押します。ボタンは **Update** に変わり、そのときの数式、参照、グリッドで、
   同じウィンドウを作り直せます。

## 例

`m1` は、Calculator ではそのウィンドウのデータ、Create Data では 1 番目の参照です。
座標（`x`、`y`、`r`）は、データの物理単位です。

### 値の変換と規格化

| 目的 | 数式 |
|---|---|
| ゲインとオフセット | `m1 * 2.5 - 100` |
| フレームごとに最大値で規格化 | `m1 / m1.Max()` |
| フレームごとに 0〜1 へ引き伸ばす | `(m1 - m1.Min()) / (m1.Max() - m1.Min())` |
| スタック全体を共通の最大値で規格化 | `m1 / m1.MaxAll()` |
| 平方根（負の値は 0 にする） | `sqrt(max(m1, 0))` |
| フレームの最大値を基準にしたデシベル | `10 * log10(m1 / m1.Max())` |

### しきい値とマスク

| 目的 | 数式 |
|---|---|
| しきい値より小さい値を 0 にする | `m1 > 500 ? m1 : 0` |
| 二値画像 | `m1 > 500` |
| マスクした画素を欠損値（NaN）にする | `m1 > 500 ? m1 : 0.0 / 0.0` |
| 原点を中心とする半径 5 の円内を残す | `m1 * circ(r / 5)` |
| (2, -1) を中心とする円内を残す | `m1 * circ((x - 2) / 5, (y + 1) / 5)` |
| 滑らかなガウス窓関数を掛ける | `m1 * gauss(r, 10)` |

### 隣の画素、ほかのフレーム、シフト

| 目的 | 数式 |
|---|---|
| 右隣の画素との差 | `m1[ix + 1, iy] - m1` |
| 勾配の大きさ（中心差分、画素あたり） | `hypot((m1[ix + 1, iy] - m1[ix - 1, iy]) / 2, (m1[ix, iy + 1] - m1[ix, iy - 1]) / 2)` |
| 左右反転（グリッドが x = 0 について対称な場合） | `m1(-x, y)` |
| x 方向に 0.5 単位ずらす（補間あり） | `m1(x - 0.5, y)` |
| 最初の時刻を引く（Time 軸が必要） | `m1 - m1[ix, iy, it:0]` |
| 1 つ前の時刻との差 | `m1 - m1[ix, iy, it: it - 1]` |
| 同じで、最初の時刻は 0 にする | `num(m1 - m1[ix, iy, it: it - 1])` |
| 2 つのチャンネルの比（Channel 軸が必要） | `m1[ix, iy, ic:0] / m1[ix, iy, ic:1]` |
| フレーム番号 0 を引く | `m1 - m1[ix, iy, 0]` |

### ウィンドウの組み合わせ（Create Data）

| 目的 | 数式 |
|---|---|
| 差 | `m1 - m2` |
| フラットフィールド補正（`m1` 信号、`m2` フラット、`m3` ダーク） | `(m1 - m3) / (m2 - m3)` |
| グリッドが異なるデータの差 | `m1(x, y) - m2(x, y)` |
| ずらして重ねる（欠けた部分は無視） | `sum(m1(x - 0.5, y), m2(x, y))` |

### データの生成（参照なしの Create Data）

| 目的 | 数式 |
|---|---|
| sin と cos の積 | `sin(x) * cos(y)` |
| 標準偏差 0.2 のガウススポット | `gauss2d(x, y, 0.2)` |
| 半径 0.5、幅 0.05 のリング | `ring(r, 0.5, 0.05)` |
| 周期 0.25 の縞 | `1 + cos(tau * x / 0.25)` |
| チャージ 3 のらせん位相（0〜2π） | `mod(3 * atan2(y, x), tau)` |
| 外へ進む波（Time 軸、1 周期 20 フレーム） | `cos(tau * (r / 0.5 - it / 20))` |
| 焦点を通る集光ビーム（Z 軸、レイリー長 1） | `gauss2d(x, y, 0.2 * sqrt(1 + z * z)) / (1 + z * z)` |
| ノイズを含むテスト画像 | `poisson(100 * gauss2d(x, y, 0.3)) + randn(10, 2)` |

## 変数

| 変数 | 意味 |
|---|---|
| `ix`、`iy` | 画素のインデックス（0 から）。`iy = 0` は一番下の行 |
| `x`、`y` | 画素の物理座標 |
| `r` | `sqrt(x*x + y*y)`。座標の原点からの距離 |

データの軸ごとに、インデックスと値の変数が加わります。

| 軸の名前 | インデックス | 値 |
|---|---|---|
| `Z` | `iz` | `z` |
| `Channel` | `ic` | `c` |
| `Time` | `it` | `t` |
| その他の軸（順に） | `ia1`、`ia2`、… | `a1`、`a2`、… |

使える変数は、ダイアログに表示されます。Calculator では、ウィンドウのデータの軸です。
1 フレームだけを処理するときは、現在の位置になります。

変数名と参照名は、大文字と小文字を区別します。関数名、定数、`Max` / `Min` は区別しません。

## データの読み方

| 書き方 | 得られる値 |
|---|---|
| `m1` | 計算中の画素の値（`m1[ix, iy]` と同じ） |
| `m1[ix, iy]` | 指定した画素の値。整数でないインデックスは丸めます |
| `m1[ix, iy, frame]` | フレーム番号（0 から）で指定したフレームの画素の値 |
| `m1[ix, iy, iz:2]` | Z 軸の位置 2 にあるフレームの画素の値 |
| `m1(x, y)` | 物理位置の値（双一次補間） |
| `m1(x, y, frame)` | 同じく、フレームを指定。軸の指定も上と同じ形でできます |
| `m1.Max()`、`m1.Min()` | 読んでいるフレームの最大値 / 最小値 |
| `m1.Max(frame)`、`m1.Min(frame)` | 指定したフレームの最大値 / 最小値 |
| `m1.MaxAll()`、`m1.MinAll()` | 全フレームの最大値 / 最小値 |

- `m1` と `m1[ix, iy]` は、**インデックス**で画素を対応させます。グリッドが異なる場合は `m1(x, y)` を使います。
- 軸は、インデックス変数の名前（`iz`、`ic`、`it`、`ia1`、…）で指定し、複数指定できます:
  `m1[ix, iy, iz:2, it:0]`。指定しない軸は、位置が変わりません。位置には式を書けるので、
  `it: it - 1` も有効です。フレーム番号と軸の指定は併用できません。
- フレームを指定しない場合に読むフレーム:
  - **Calculator**: 処理中のフレーム。
  - **Create Data**: 参照のフレーム数が結果と同じなら、計算中のフレーム。異なる場合は、
    参照ウィンドウが表示しているフレーム。
- `Complex` などの構造を持つデータは、ウィンドウが表示している値モード（振幅、位相、実部など）の数値として読みます。

## 演算子と定数

優先順位の低い順です。

| 演算子 | 備考 |
|---|---|
| `a ? b : c` | `a` が真なら `b`、偽なら `c` |
| <code>&#124;&#124;</code> | |
| `&&` | |
| `==` `!=` `<` `<=` `>` `>=` | 結果は 1 か 0 |
| `+` `-` | |
| `*` `/` `%` | `%` の符号は左の値に従います。`mod` も参照 |
| `-` `+` `!`（単項） | |

すべての値は数値で、0 以外は真とみなします。定数は `pi`、`tau`（2π）、`e`、`true`、`false` です。
べき乗は `pow(a, b)` と書きます。`^` は使えません。数式は ASCII 文字だけで書きます。

## 関数

| 分類 | 関数 |
|---|---|
| 三角関数 | `sin` `cos` `tan` `asin` `acos` `atan` `atan2(y, x)` `sinh` `cosh` `tanh` |
| 指数・対数 | `exp` `log`（自然対数） `log2` `log10` `sqrt` `pow(x, y)` `hypot(x, y)` |
| 丸めと範囲 | `abs` `sign` `floor` `ceil` `round`（0.5 は 0 から遠い方へ） `min(a, b)` `max(a, b)` `clamp(x, min, max)` `fract` `mod(a, b)` |

### 形状

| 関数 | 値 |
|---|---|
| `rect(x)` | \|x\| ≤ 0.5 で 1、それ以外は 0 |
| `circ(r)` | \|r\| ≤ 1 で 1、それ以外は 0 |
| `circ(x, y)` | x² + y² ≤ 1 で 1、それ以外は 0 |
| `tri(x)` | \|x\| < 1 で 1 − \|x\|、それ以外は 0 |
| `sinc(x)` | sin(πx) / (πx)。0 では 1 |
| `ring(r, radius, width)` | `r` が `radius` から `width/2` 以内なら 1、それ以外は 0 |
| `gauss(x, sigma)` | exp(−x² / 2σ²) |
| `gauss2d(x, y, sigma)` | exp(−(x² + y²) / 2σ²) |

### 補助

| 関数 | 値 |
|---|---|
| `step(edge, x)` | `x < edge` で 0、それ以外は 1 |
| `smoothstep(edge0, edge1, x)` | 2 つの境界の間で、0 から 1 へ滑らかに増加 |
| `lerp(a, b, t)` | `a + (b - a) * t` |
| `sum(a, b, ...)` | 2 つ以上の値の和。NaN は無視し、すべて NaN のときだけ NaN |
| `num(v)` / `num(v, a)` | `v`。`v` が NaN なら 0 / `a` |

### 乱数

| 関数 | 値 |
|---|---|
| `rand()` / `rand(min, max)` | 一様乱数 |
| `randn()` / `randn(mean, sigma)` | 正規乱数 |
| `poisson(lambda)` | 平均 `lambda` のポアソン乱数 |
| `salt(p)` | 確率 `p` で 1、それ以外は 0 |
| `noise(x, y)` | 0〜1 の滑らかなノイズ。同じ位置では常に同じ値 |

`noise` 以外の乱数は、評価のたびに新しい値になります。ソースに追従する結果の更新でも同じです。

## データの外の値（NaN）

データの外や、存在しないフレームを読むと NaN になり、NaN は演算を通して伝わります。
置き換えるには `num(v)` か `num(v, a)` を使います。ある値だけを足すには `sum(...)` を使います。

```
num(m1[ix + 10, iy]) + m2
```

NaN は自分自身と等しくないので、`v != v` で判定できます。条件として使うと、NaN は 0 ではないので真になります。

## ソースに追従する結果

### Sync source data（Calculator）

結果のウィンドウは、ソースの現在のフレームに追従し、ソースが再描画されると再計算されます。
複数フレームのデータでは、**This frame only** をチェックすると選べるようになります。
このウィンドウの数式は、**Data > View > Edit Formula…** で後から変更できます。

### Keep updated（Create Data）

結果は 1 フレームで、各参照が表示しているフレームから計算されます。参照が再描画されたとき、
フレームや値モードが変わったとき、データが置き換えられたときに、再計算されます。

- MxPlot.App では、結果はウィンドウ一覧に **fx** の印が付き、選択中は入力元に色が付きます。
  コンテキストメニューの **Edit Formula…** で数式を変更できます。
- 結果か参照のウィンドウを閉じると追従をやめ、通常のウィンドウとして残ります。
- 結果は、別の結果の参照にできます。自分自身に依存させることはできません。
- 参照のサイズが変わっても、結果のグリッドは変わりません。参照が届かない画素は NaN になります。

## ホストアプリケーションから Create Data を使う

`CreateDataDialog` は `MxPlot.UI.Avalonia` に含まれます。参照できるウィンドウは、ホストが渡します。

```csharp
using MxPlot.UI.Avalonia.Views;

var plotters = new List<MatrixPlotter>(); // アプリケーションが管理しているウィンドウ

var dialog = CreateDataDialog.Show(owner: null, candidates: () => plotters);
dialog.LiveCalculationStarted += calc =>
{
    // calc.Ended が発生するまで、calc.Result は calc.Inputs に追従する。
};
```

UI スレッドで呼び出してください。

## 注意と制限

- 結果は `double` です。新しい結果のサイズは、画素数 × 8 バイトです。
- Virtual データでは、`MaxAll()` と `MinAll()` は、値の範囲が分かっているフレームだけを対象にします。
- `m1(x, y)` の補間は 1 フレーム内だけです。ほかの軸の方向には補間しません。
- 数式の履歴は、アプリケーションの実行中だけ保持されます。
